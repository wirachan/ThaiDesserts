# เสน่ห์ขนมไทย (ThaiDesserts) 🍮✨

เว็บแอปพลิเคชันรวบรวมมรดกทางวัฒนธรรมและภูมิปัญญาแห่งรสชาติของ **"ขนมไทย"** ทั้งตำรับโบราณและชาววัง พร้อมระบบสุ่มเมนูประจำวัน ตัวกรองระดับความหวาน และการค้นหาอัจฉริยะ

![ขนมทองหยิบ](thong-yib.png)

## 🌟 ฟีเจอร์เด่น (Key Features)

- **ทำเนียบสำรับขนมไทย**: รวบรวมขนมไทยเลิศรส พร้อมภาพประกอบ ข้อมูลวัตถุดิบ ระดับความหวาน แคลอรี่ และประวัติความเป็นมา
- **ระบบสุ่มขนมแนะนำ ("วันนี้กินอะไรดี?")**: วงล้อสุ่มเมนูพร้อมแสดงระดับความหวานและความหมายมงคล
- **ระบบค้นหาและตัวกรองแบบเรียลไทม์**:
  - กรองตามหมวดหมู่ (เช่น ขนมตระกูลทอง, ขนมนึ่ง/กวน, ขนมกะทิ, ขนมทอด/อบกรอบ)
  - กรองตามระดับความหวาน (หวานน้อย, ปานกลาง, หวานฉ่ำ)
  - ค้นหาตามชื่อขนมและวัตถุดิบ พร้อมไฮไลท์คำค้นหา
  - แท็กยอดนิยม (#ขนมมงคล, #ชาววัง, #กะทิสด ฯลฯ)
- **ประวัติศาสตร์และความหมายมงคล**: Modal แสดงเรื่องราวและที่มาของแต่ละเมนูอย่างละเอียด
- **Responsive & Modern UI**: ออกแบบด้วย Tailwind CSS รองรับการใช้งานทั้งบนมือถือและเดสก์ท็อป

## 📁 โครงสร้างโปรเจกต์ (Project Structure)

```
ThaiDesserts/
├── index.html        # โครงสร้างหน้าเว็บหลัก (HTML5 + Tailwind CSS)
├── style.css         # สไตล์เพิ่มเติมและการตกแต่งลวดลายไทย
├── app.js            # ตรรกะการทำงาน ค้นหา กรอง และสุ่มเมนู
├── data.js           # ฐานข้อมูลเมนูขนมไทย
├── thong-yib.png     # ภาพขนมทองหยิบความละเอียดสูง
└── README.md         # เอกสารประกอบโปรเจกต์
```

## 🚀 วิธีเปิดใช้งาน (Getting Started)

เปิดไฟล์ `index.html` บนเว็บเบราว์เซอร์ใดก็ได้ (เช่น Chrome, Edge, Firefox, Safari) หรือเปิดผ่าน Live Server
